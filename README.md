# Онлайн-система цифровизации управления фитнес-клубом

Онлайн-система цифровизации управления фитнес-клубом позволяет автоматизировать ключевые бизнес-процессы малого фитнес-клуба: управление клиентами, тренерами, абонементами, услугами, расписанием и учетом посещений. 

Просмотр расписания групповых тренировок, информации о тренерах, абонементах и услугах доступен всем неавторизованным пользователям. 

**Роли и возможности:**
* **Клиенты** системы (зарегистрированные пользователи) могут приобретать абонементы и разовые услуги, записываться на персональные тренировки, просматривать тренировочные планы, уведомления и текущее количество посетителей в клубе.
* **Тренеры** имеют доступ к личному кабинету для управления слотами персональных тренировок, составления планов тренировок и отправки уведомлений клиентам.
* **Администратор** обладает полными правами на управление клиентами, тренерами, справочниками (зоны, залы, услуги, абонементы), расписанием и фиксацию посещений клуба.

Система разработана в виде веб-приложения (тонкий клиент) и не требует предварительной установки на устройства пользователей.

## Инструкция по настройке и запуску приложения

### 1. Установка и настройка СУБД MySQL

Установите MySQL Server, MySQL Workbench и MySQL Shell с официального сайта MySQL. В процессе установки задайте пароль для пользователя `root` и запомните его. 

После установки проверьте запуск службы MySQL. 
Для Windows: откройте службы через `Win + R`, введите `services.msc`, найдите службу "MySQL80" и запустите её. 
Альтернативно выполните в командной строке (от имени администратора):
```cmd
net start MySQL80
```

### 2. Создание базы данных

Откройте MySQL Workbench и подключитесь к локальному серверу (Local instance MySQL80), введя пароль `root`. 

Создайте новую базу данных. Вы можете выполнить следующий SQL-запрос:
```sql
CREATE DATABASE IF NOT EXISTS fitness_club DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Затем откройте приложенный файл `create_database.sql` в MySQL Workbench, выберите созданную базу данных `fitness_club` и выполните скрипт для создания всех таблиц, связей и индексов.

### 3. Настройка и запуск Spring-приложения

Получите исходный код проекта и распакуйте или склонируйте его в рабочую директорию.

Настройте файл `application.properties` (обычно находится в `src/main/resources/`). Для подключения к базе данных укажите следующие параметры:

```properties
# Настройки подключения к БД
spring.datasource.url=jdbc:mysql://127.0.0.1:3306/fitness_club?allowPublicKeyRetrieval=true&useSSL=false&serverTimezone=Europe/Moscow
spring.datasource.username=root
spring.datasource.password=[ВАШ_ПАРОЛЬ_ОТ_MYSQL]
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# Настройки JPA/Hibernate
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQLDialect

# Настройки сервера
server.port=8080
```
*Замените `[ВАШ_ПАРОЛЬ_ОТ_MYSQL]` на пароль, заданный для пользователя `root` при установке MySQL.* Обратите внимание, что в проекте уже настроена таймзона через Java-конфигурации (`ApplicationTimeConfiguration.java`, `FitnessClubManagementDigitalizationSystemApplication.java`), однако указание `serverTimezone` в URL также является хорошей практикой.

### 4. Запуск приложения

Откройте проект в IDE (например, IntelliJ IDEA). Найдите главный класс `FitnessClubManagementDigitalizationSystemApplication` (аннотированный `@SpringBootApplication`) и запустите его.

Проверьте логи приложения на наличие ошибок. Убедитесь в успешном подключении к базе данных. После успешного запуска система будет доступна в браузере по адресу: `http://localhost:8080`.
